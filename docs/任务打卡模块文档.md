# 任务打卡模块文档

## 模块概述

任务打卡模块是一个个人任务管理系统，支持创建带日期范围的任务计划并每日打卡追踪完成情况。模块采用前后端分离架构，后端 Spring Boot + MyBatis-Plus，前端 Vue 3 + Element Plus。

## 页面结构

统一入口 `/task`，三个 Tab 页：

| Tab | 功能 | 说明 |
|---|---|---|
| 今日打卡 | 一键打卡 + 日期导航 | 默认 Tab，展示当日待执行任务，支持快速打卡和编辑 |
| 打卡日历 | 月度热力图 + 统计 | 类似 GitHub 绿点图，直观展示打卡情况 |
| 任务管理 | 增删改 + 筛选 + 统计 | 管理任务计划，按类型/状态筛选，查看时段统计 |

## 关键业务逻辑

### 今日任务筛选

`getTodayTasks(date)` 查询逻辑：
1. 查出所有 `status=1`（进行中）且 `del_flag=0` 的任务计划
2. **日期范围过滤**：startTime 为空或 <= 当天（任务已开始），endTime 为空或 >= 当天（任务未结束，null 表示一直持续）
3. 过滤 `week_day`：null/空串表示每天执行，否则匹配当天星期几（1=周一...7=周日）
4. 查出指定日期的所有打卡记录，按 `task_id` 建立 Map
5. 合并任务信息和打卡状态，按 `sort` 排序返回

### 一键打卡幂等校验

`quickCheckIn` 在插入前检查同一 `task_id` + `check_date` 是否已存在打卡记录，存在则抛出 `ServiceException`。

### 级联删除

删除任务计划时，通过 `TaskCheckInMapper` 先删除关联的打卡记录，再删除计划本身。避免通过 `TaskCheckInService` 注入导致循环依赖。

### 连续打卡计算

`calculateStreak(today)` 从今天往前逐天查询是否有 `check_status=1` 的打卡记录，直到某天没有则停止，返回连续天数。

### 统计接口

`getPlanStats(taskType, startTime, endTime)` 逻辑：
1. 按 taskType 查任务计划总数
2. 按 taskType + 时间范围查总打卡次数
3. 同条件查已完成（`check_status=1`）次数
4. 计算完成率 = 已完成 / 总打卡 * 100

### 前端交互说明

- **任务计划的 startTime/endTime**：使用 `el-date-picker` 选择年月日（YYYY-MM-DD 格式），完成日期支持"一直持续"开关（开启后 endTime 为 null）
- **打卡的实际时间 actualStartTime/actualEndTime**：使用 `el-time-select` 选择时间段（HH:mm 格式），记录当天实际执行时间
- 日期范围显示规则：两日期都有显示"2026-04-26 至 2026-06-30"，仅开始日期显示"2026-04-26 起"

## 注意事项

1. **userId 暂时硬编码为 1**，后续需对接 Sa-Token 登录态
2. **start_time/end_time 字段为 varchar**，存日期格式（YYYY-MM-DD），endTime 为 null 表示一直持续
3. **打卡状态枚举未定义常量类**，前后端都用字符串 "0"/"1"/"2"，建议后续定义枚举
4. **ongoing 标志为前端概念**，不存入数据库，由 endTime 是否为 null 推导
5. **TaskCheckInPO 的 totalCount/completedCount** 使用 `@TableField(exist = false)` 标记为非数据库字段
